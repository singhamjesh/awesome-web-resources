# 🛡️ Safety, Privacy & Responsible Use

This repository is a directory of links, not a guarantee of safety, accuracy, legality, availability, or endorsement.

## Before using an unfamiliar website

- Check the domain carefully for misspellings, impersonation, and suspicious redirects.
- Look for an official About page, documentation, contact details, and a clear privacy policy.
- Be cautious if a site asks you to install an unknown executable, browser extension, certificate, or profile.
- Do not enter passwords, API keys, payment details, or private documents unless you trust the service and understand how your data will be handled.
- Use a password manager and unique passwords. Enable multi-factor authentication where possible.
- Keep your browser, operating system, and security tools updated.

## Downloads and open-source repositories

Before cloning or installing a project:

1. Read the README and installation commands.
2. Check the repository owner, recent activity, releases, issue history, and license.
3. Inspect install scripts and dependency changes before running them.
4. Avoid running unknown code with administrator/root privileges.
5. Use a virtual machine, container, or disposable environment when testing unfamiliar software.
6. Scan downloaded files and verify release checksums/signatures when the project provides them.
7. Never paste secrets into public issues, code snippets, AI tools, or logs.

A popular repository is not automatically safe, maintained, or suitable for production.

## Cybersecurity and OSINT

- Practice security testing only on systems you own or have explicit permission to assess.
- Use training environments such as TryHackMe, Hack The Box, PortSwigger Web Security Academy, OverTheWire, and CyberDefenders for authorized practice.
- Do not use IP-logging links or tracking tools to secretly monitor people.
- Do not dox people, harass them, bypass access controls, or collect personal information without a lawful basis.
- Treat OSINT results as leads, not proof. Data can be outdated, incorrect, or refer to someone else.
- Follow applicable laws, terms of service, and organizational policies.

## AI services

- Review privacy, retention, and training terms before uploading sensitive content.
- Do not submit customer records, private source code, credentials, medical information, or confidential business files unless approved for that service.
- Verify generated code, citations, facts, and commands before using them.
- Review the permissions of AI agents and extensions, especially when they can read files, run shell commands, or access accounts.

## Media, copyright, and licenses

- Download or reuse media only when you have the rights or permission to do so.
- Respect the terms of the source website and applicable copyright law.
- Check each repository's actual license before copying, modifying, redistributing, or using it commercially.
- A link in this directory does not imply endorsement of the linked site's content.

## Medical and official documents

Websites advertising certificate generation must not be used to fabricate medical records, impersonate professionals, or misrepresent medical status. Obtain legitimate documents from the appropriate qualified provider or authority.

## Report a problem

If a link becomes malicious, misleading, broken, or inappropriate, open an issue or pull request with the URL and a brief explanation. Do not include personal information, passwords, tokens, or other secrets in the report.


## Abuse-prone services

Some links in this directory relate to IP logging, identity lookup, or call-bombing services. They are listed for awareness and security education, not as endorsements. Do not use them to harass, impersonate, track, or collect data about anyone without permission. Prefer consent-based testing in a controlled environment.
