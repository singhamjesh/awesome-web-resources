## 🤝 Contributing

Found a useful site or open-source project? Contributions are welcome!

1. Check that the URL works and is relevant.
2. Choose the most appropriate category.
3. Add a concise, accurate description.
4. For GitHub projects, check recent activity, license, and documentation.
5. For trend claims, include the date and evidence; popularity can change quickly.
6. Submit a pull request.

Use this format:

```markdown
| [Website Name](https://example.com/) | A short, useful description of its purpose. |
```

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full guidelines and [SAFETY.md](SAFETY.md) for responsible use.
